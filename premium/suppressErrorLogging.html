$suppressErrorLogging

Premium

Disable error logging for the command in bot logs.

Syntax

$suppressErrorLogging

Example

$nomention
Hello world!
$createChannel[;]
$suppressErrorLogging
!example ❌ Function $createChannel at 3:17 returned an error: expected valid value in position 1, got empty value
