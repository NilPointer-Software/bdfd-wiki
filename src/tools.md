# Useful Tools

Here is list of useful tools that can help you in your bot development process:

## Official Bot Designer For Discord Tools
- **[Permission calculator](https://botdesignerdiscord.com/tools/permission-calculator)** - A tool to help you calculate the required permissions for your bot based on its functionalities.
- **[Snowflake decoder](https://botdesignerdiscord.com/tools/snowflake-decoder)** - A tool to decode Discord snowflakes into human-readable information.
- **[BDScript editor](https://botdesignerdiscord.com/tools/playground)** - An online editor for writing  BDScript code snippets.
