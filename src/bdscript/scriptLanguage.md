# $scriptLanguage
Returns the name of scripting language used by the command.

## Syntax
```
$scriptLanguage
```

```admonish note title="Possible Outputs"
- BDScript
- BDScript 2
- BDScript Unstable
```

## Example
```
$nomention
This command uses $scriptLanguage.
```
