# $hostingExpireTime 
Returns your bot's hosting expiration date.

## Syntax
``` 
$hostingExpireTime
```

```admonish tip title="Timestamp Converter"
You can use our ["Timestamp Converter" tool](../tools/timestamp.md) to work with unixtime!
```

## Example
``` 
$nomention 
My hosting expiration date: $hostingExpireTime 
```
