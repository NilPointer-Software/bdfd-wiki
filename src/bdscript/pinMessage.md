# $pinMessage
Pins the bot's response message in the current channel.

```admonish warning title="Limit"
A channel can have a maximum of 250 pinned messages.
```

## Syntax
```
$pinMessage
```

## Example
```
$nomention
$pinMessage
This is a cool pinned message! 😎
```
