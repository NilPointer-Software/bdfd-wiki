# $parentID
Returns the current channel's parent category ID.

## Syntax
```
$parentID
```

## Example
```
$nomention
Current category: $parentID
```

```discord yaml
- user_id: 803569638084313098
  username: RainbowKey
  color: "#E67E22"
  content: |
    !example
- user_id: 1009018156494368798
  username: BDFD Support
  color: "#378afa"
  bot: true
  verified: true
  content: |
    Current category: 567445224989786132
```
