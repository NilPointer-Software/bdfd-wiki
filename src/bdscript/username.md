# $username
Returns the username of the author of the message.

## Syntax
```
$username
```

## Example
```
$nomention
Hello $username!
```

``` discord yaml
- user_id: 803569638084313098
  username: RainbowKey
  color: "#E67E22"
  content: |
    !example
- user_id: 1009018156494368798
  username: BDFD Support
  color: "#378afa"
  bot: true
  verified: true
  content: |
    Hello rainbow_key!
```
