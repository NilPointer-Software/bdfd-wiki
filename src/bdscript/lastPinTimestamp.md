# $lastPinTimestamp
Returns the last pinned message timestamp in the current channel.

## Syntax
```
$lastPinTimestamp
```

## Example
```
$nomention
Last Pin Timestamp: $lastPinTimestamp
```

```discord yaml
- user_id: 803569638084313098
  username: RainbowKey
  color: "#E67E22"
  content: |
    !example
- user_id: 1009018156494368798

  color: "#378afa"

  content: |
    Last Pin Timestamp: 1753454520
```
