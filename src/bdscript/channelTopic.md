# $channelTopic
Returns the topic of the channel that the command is being used in.

## Syntax
```
$channelTopic
```

## Example
```
$nomention
Topic of this channel is: $channelTopic
```

``` discord yaml
- user_id: 803569638084313098
  username: RainbowKey
  color: "#E67E22"
  content: |
    !example
- user_id: 1009018156494368798
  username: BDFD Support
  color: "#378afa"
  bot: true
  verified: true
  content: |
    Topic of this channel is: A testing channel!
```
