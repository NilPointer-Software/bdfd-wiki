# $randomChannelID
Returns a random channel ID from the current server.

## Syntax
```
$randomChannelID
```

## Example
```
$nomention
Random Channel: $channelName[$randomChannelID]
```

``` discord yaml
- user_id: 803569638084313098
  username: RainbowKey
  color: "#E67E22"
  content: |
    !example
- username: BDFD Support
  user_id: 1009018156494368798
  color: "#378afa"
  bot: true
  verified: true
  content: |
    Random Channel: 😎main-chat
```
