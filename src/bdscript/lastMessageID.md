# $lastMessageID
Returns last message ID in the current channel (**excluding the bot's response**).

## Syntax
```
$lastMessageID
```

## Example
```
$nomention
Last Message ID: $lastMessageID
```

```discord yaml
- user_id: 803569638084313098
  username: RainbowKey
  color: "#E67E22"
  content: |
    !example
- user_id: 1009018156494368798
  username: BDFD Support
  color: "#378afa"
  bot: true
  verified: true
  content: |
    Last Message ID: 1328323490490880032
```
