# $suppressErrorLogging
<div class="functionTags">
  <span id="PremiumTag">Premium</span>
</div>

Disable error logging for the command in bot logs.

## Syntax
```
$suppressErrorLogging
```

## Example
```
$nomention
Hello world!
$sum[5;10
$suppressErrorLogging
```
